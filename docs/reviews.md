# Отзывы ART Lab

Блоки уже подключены на главной, в арт-лагере и на странице праздников — перед завершающим предложением записаться. На странице мастер-классов блок не добавлен.

## Где менять отзывы

Открой **`src/data/reviews.json`**. Все отзывы находятся в одном файле:

- `home` — главная: 5 отзывов.
- `camp` — арт-лагерь: 5 отзывов.
- `celebrations` — праздники: 6 отзывов. На одном из присланных скриншотов были два отдельных сообщения; добавлены оба.

Порядок объектов в массиве задаёт порядок карточек. Первая карточка шире остальных на планшетах и компьютерах. Для добавления скопируй любой объект внутри нужного массива; для удаления удали объект целиком. Компонент подстроится под количество.

Пример отзыва из переписки:

```json
{
  "id": "unique-review-id",
  "author": "Anna",
  "source": "message",
  "text": {
    "ru": "Текст на русском.\n\nНовый абзац.",
    "en": "The English translation.\n\nA new paragraph.",
    "et": "Eestikeelne tõlge.\n\nUus lõik."
  }
}
```

`id` должен быть уникальным внутри массива и оставаться стабильным, когда меняешь текст. `author` — имя автора. Если на скриншоте имени не было, оно не придумано: оставлены `"author": ""` и `"authorLabel": "parent"`, `"guest"` или `"participant"`. Такая подпись переводится автоматически.

`source` — `message` для переписки либо `google` для отзыва из Google Maps. Только для отзыва с реальной оценкой Google добавляй `"rating": 5`; сообщения из переписки отображаются без звёзд.

`text.ru`, `text.en`, `text.et` — полный текст и переводы. Русские тексты перенесены с присланных скриншотов; в отдельных местах приведены к обычному оформлению пробелы и пунктуация. Ответы студии, реакции и относительные даты не включены. На ET/EN есть пометка о переводе с русского. Если перевод временно отсутствует, компонент покажет русский оригинал с правильным атрибутом языка.

Не вставляй HTML: содержимое показывается как обычный текст. Абзацы разделяй `\n\n`. Кавычки внутри строки записывай как `\"`. Длинный отзыв автоматически получает кнопку «Читать полностью», короткий показывается целиком. Отдельный сокращённый текст редактировать не нужно.

## Оценка Google Maps

В начале того же файла находятся настройки:

```json
"googleRating": { "value": 5, "scale": 5 }
```

Оценка **5 из 5** добавлена по твоему запросу. Это вручную заданное значение: сайт не обращается к Google API и не обновляет оценку автоматически. При изменении рейтинга обнови `value`. Чтобы убрать плашку, поставь `"googleRating": null`.

`settings.googleMapsUrl` открывает именно карточку ArtLab из твоей ссылки. `settings.instagramUrl` задаёт ссылку под блоками лагеря и праздников.

## Заголовки и кнопки

Тексты интерфейса лежат отдельно:

- `src/locales/ru/reviews.json`
- `src/locales/en/reviews.json`
- `src/locales/et/reviews.json`

`pages.home`, `pages.camp`, `pages.celebrations` содержат заголовки и описания. Тексты отзывов находятся в `src/data/reviews.json`, а не в этих файлах.

## Переставить блок

Общий компонент: `src/components/sections/ReviewsSection.jsx`.

На главной его положение задано в `src/pages/Home/Home.jsx`:

```jsx
<ReviewsSection variant="home" />
```

Для лагеря и праздников положение задано в `src/pages/Formats/CreativeFormatPage.jsx`:

```jsx
{(isCampPage || isCelebrationsPage) && (
  <ReviewsSection variant={formatKey} />
)}
```

При переносе перемещай существующий блок, чтобы не появилось две копии. Можно передать `id` и `className`, например `<ReviewsSection variant="camp" id="camp-reviews" />`.

## Проверка после редактирования

В терминале проекта выполни `npm run check`, затем открой три страницы через `npm run dev` и проверь русский, английский и эстонский варианты. Проверяй телефон и компьютер, раскрытие длинного отзыва и ссылку Google Maps.

В этой среде проверены рендер всех трёх страниц на трёх языках, состав отзывов, подписи, ссылки, уникальные ID, линтер и production-сборка. Браузер среды блокирует локальный адрес; визуальная проверка и реальный клик по кнопкам в браузере не завершены.
